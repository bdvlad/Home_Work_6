# Моя візитка

Адаптивний односторінковий сайт-візитка Василя Навчального, вайб кодера. Сторінка представляє фахівця в діловій стилістиці з легким гумором: про себе, навички, компетенції, послуги, відгуки та контакти.

У шапці є перемикач світлої та темної теми. Перший візит бере тему системи. Після натискання вибір зберігається в браузері.

У блоці контактів, в одній колонці з рештою даних приймальні, є форма: ім’я, електронна пошта, телефон і повідомлення. Ім’я, пошта і повідомлення обов’язкові. Телефон можна не заповнювати; якщо він є, перевіряється формат. Помилки з’являються під полем. Сайт статичний, тож після успішної перевірки лист лишається підтвердженням на сторінці і нікуди не відправляється.

## Технології

- HTML5
- CSS3 (flex, grid, медіазапити, змінні для світлої та темної теми)
- JavaScript без фреймворків
- Google Fonts: EB Garamond

Збірка та фреймворки не використовуються.

## Структура

```
my-portfolio/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── theme.js
│   └── contact.js
└── README.md
```

- `js/theme.js` перемикає тему і записує вибір у `localStorage`.
- `js/contact.js` перевіряє поля форми перед надсиланням.

## Запуск

Потрібен лише браузер.

1. Відкрий папку проєкту.
2. Запусти `index.html` подвійним кліком або через «Open with Live Server» у редакторі.

Локальний сервер (за бажанням):

```bash
python -m http.server 8765
```

Після цього сайт доступний за адресою [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
